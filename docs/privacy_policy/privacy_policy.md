# VideoDefaults Privacy Policy

Last updated: July 31, 2026

VideoDefaults is a browser extension that applies the user's preferred
video playback speed and provides keyboard-based navigation controls on
YouTube.

## Data processed by the extension

To provide its functionality, VideoDefaults processes the following
information locally on the user's device:

- extension settings, including the preferred playback speed and
  keyboard navigation settings;
- the URL of the currently open YouTube page, in order to detect
  navigation between videos;
- information about the video element and visible interactive elements
  on the YouTube page;
- keyboard input used to activate the extension's keyboard shortcuts.

## Local storage

Extension settings are stored locally using the Chrome Storage API.

## Data transmission

VideoDefaults does not transmit personal data, browsing activity,
website content, extension settings, or keyboard activity to the
developer or to any third party.

VideoDefaults does not use analytics, advertising services, tracking
technologies, or remote servers.

## Data sharing and sale

VideoDefaults does not sell, rent, share, or transfer user data to third
parties.

## Data retention and deletion

Settings remain stored locally until the user changes them, clears the
extension's data, or uninstalls the extension.

## Changes to this policy

This privacy policy may be updated when the extension's functionality or
data practices change. Material changes will be disclosed before the
new data practices are introduced.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the
Chrome Web Store User Data Policy, including the Limited Use
requirements.
