# edge-extension

Edge edition of VideoDefaults (Manifest V3). Edge is Chromium-based, so this
edition is identical to `apps/chrome-extension/` except for its own
`manifest.json` (kept separate so Edge-specific fields can diverge later).
`src/`, `assets/`, and `lib/` are generated by `scripts/sync-extension-lib.sh`.

Build: `bash scripts/package-extension.sh edge-extension`
Load unpacked: run the sync script, then point `edge://extensions` (Developer
mode → Load unpacked) at this directory.
